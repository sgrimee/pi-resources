# Changelog

## [0.1.0] - 2026-10-19

- Add `/resources` to browse loaded context files, skills, prompt templates, and extensions without a model call.
- Group resources by category with theme-aware colors, counts, source badges, and a selection detail panel.
- Support live search, category filters, keyboard/mouse navigation, resizing, and an RPC selector fallback.
- Include event-only extensions using a lifecycle-scoped runtime inventory bridge.
- Package as an independently installable GitHub/npm Pi extension.
